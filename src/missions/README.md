# Missões

`index.ts` é o cadastro dos nomes e IDs das missões. Os personagens usam `unlockRequirement` para referenciar uma missão por ID. O texto mostrado na seleção vem desse cadastro.

Não há ainda sistema de progresso, objetivos, conta do jogador ou bloqueio de personagens por conclusão. Não marque uma missão como concluída apenas porque ela está cadastrada. Esses comportamentos precisarão ser implementados antes do desbloqueio real.
